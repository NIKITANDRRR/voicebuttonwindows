# 📘 VoiceButton — пошаговая настройка для новичков

> Если ты не программист и не сисадмин, а просто хочешь, чтобы программа печатала твой голос — эта инструкция для тебя. Здесь всё разжёвано по шагам. Ничего учить наизусть не нужно — просто повторяй по порядку.

---

## Что это за программа

**VoiceButton** печатает то, что ты говоришь. Держишь клавишу **F9**, говоришь в микрофон, отпускаешь **F9** — и текст появляется там, где стоит курсор (в Telegram, Word, браузере, письме — где угодно).

Работает быстро, если у тебя есть видеокарта **NVIDIA**. Без неё тоже работает, но медленнее (об этом ниже).

---

## Что нужно для работы (коротко)

| Что | Зачем |
|---|---|
| Windows 10 или 11 | сама система |
| Видеокарта NVIDIA | чтобы текст распознавался быстро |
| Драйвер NVIDIA (он же «CUDA-драйвер») | чтобы видеокарта «ожила» для программы |
| Микрофон | понятно зачем :) |

**Важно:** полный «CUDA Toolkit» (огромный набор инструментов для программистов, несколько гигабайт) ставить **НЕ нужно**. Для готовой программы достаточно обычного **драйвера NVIDIA** — именно его в разговорах часто и называют «CUDA-драйвером».

---

## Шаг 1. Проверь, есть ли у тебя видеокарта NVIDIA

1. Нажми **Win + X** (или правой кнопкой мыши по кнопке «Пуск»).
2. Выбери **«Диспетчер устройств»**.
3. Раскрой пункт **«Видеоадаптеры»**.
4. Посмотри, что там написано:
   - Видишь **«NVIDIA GeForce …»** — отлично, карта есть, иди к Шагу 2.
   - Видишь только **«Intel …»** или **«AMD …»** — видеокарты NVIDIA нет. Программа всё равно заработает (на процессоре), просто распознавать будет медленнее. Можешь сразу перейти к Шагу 4.

---

## Шаг 2. Установи (обнови) драйвер NVIDIA

Драйвер — это программа, которая «объясняет» Windows, как работать с видеокартой. Ставится один раз.

### Способ А (проще, автоматически) — через GeForce Experience

1. Открой сайт `https://www.nvidia.com/geforce-experience/` и скачай **GeForce Experience**.
2. Установи его (просто жми «Далее»).
3. Открой GeForce Experience → вкладка **«Драйверы»** → **«Проверить наличие обновлений»** → **«Установить»**.
4. Дождись окончания и перезагрузи компьютер.

### Способ Б (вручную, без лишних программ)

1. Открой `https://www.nvidia.com/download/index.aspx`.
2. Укажи свою видеокарту (серию и модель — например, GeForce RTX 3060), свою систему (Windows 10/11, 64-bit) и язык.
3. Нажми **«Найти»** → скачай драйвер → запусти скачанный файл → жми «Далее» до конца.
4. Перезагрузи компьютер.

---

## Шаг 3. Проверь, что драйвер встал правильно

1. Нажми **Win + R**, введи `cmd` и нажми Enter.
2. В чёрном окне набери `nvidia-smi` и нажми Enter.
3. Появилась таблица с названием твоей видеокарты и номером версии драйвера — всё отлично.
4. Написано `nvidia-smi не является внутренней или внешней командой` — драйвер не встал, вернись к Шагу 2.

---

## Шаг 4. Скачай и выбери нужную версию программы

На странице [Releases](https://github.com/NIKITANDRRR/voicebuttonwindows/releases) лежат два готовых файла. Выбор зависит от **объёма видеопамяти** твоей видеокарты:

| Файл | Сколько видеопамяти нужно | Для каких карт |
|---|---|---|
| `voicebutton-medium.exe` | от ~6 ГБ | RTX 2060, 3060, 4060 и похожие |
| `voicebutton-large.exe` | от ~10 ГБ | RTX 3080, 4070, 4080 и похожие |

**Как узнать объём видеопамяти:**

1. Нажми **Ctrl + Shift + Esc** (откроется Диспетчер задач).
2. Вкладка **«Производительность»** → слева **«Графический процессор» (GPU)**.
3. Смотри строку **«Выделенная память ГП»** — это и есть объём видеопамяти (в ГБ).

Если сомневаешься — бери `voicebutton-medium.exe`. Он подходит почти всегда, и точность для русского и английского у него уже отличная.

Скачай файл в любое удобное место (например, на рабочий стол).

---

## Шаг 5. Запусти программу

> ⚠️ **Важно:** программу нужно запускать **от имени администратора** — иначе она не сможет перехватывать клавишу F9 и просто не заработает.

1. Найди скачанный `.exe`-файл.
2. Нажми по нему **правой кнопкой мыши** → **«Запуск от имени администратора»**.
3. Если Windows SmartScreen спросит «Запустить?» — нажми **«Подробнее»** → **«Выполнить в любом случае»** (это нормально для программ не из магазина).
4. Если антивирус начнёт ругаться — разреши выполнение (бывает ложное срабатывание; исходники программы открыты и лежат в этом репозитории).

Чтобы не нажимать «от имени администратора» каждый раз, настрой один раз: правой кнопкой по файлу → **«Свойства»** → вкладка **«Совместимость»** → поставь галочку **«Запускать эту программу от имени администратора»** → **ОК**.

---

## Шаг 6. Первый запуск (скачается модель)

При первом запуске программа скачает «модель» распознавания речи:

- для medium — примерно **1,5 ГБ**;
- для large — примерно **3 ГБ**.

Это делается один раз. Появится окошко «Downloading Whisper … model» — просто подожди. Модель сохранится в `C:\Users\<твоё_имя>\.cache\huggingface\hub\`, и в следующий раз программа запустится сразу.

После загрузки в правом нижнем углу (в трее, возле часов) появится значок микрофона: зелёный — готов к работе, красный — идёт запись.

> Программа не открывает окно — она работает в фоне, в трее. Закрыть её можно через правый клик по значку микрофона → **Exit**.

---

## Шаг 7. Проверь, что всё работает

1. Открой любой текстовый редактор (Блокнот, Word) или чат.
2. Поставь курсор туда, куда хочешь вставить текст.
3. **Зажми и удерживай F9**, говори в микрофон.
4. **Отпусти F9** — через секунду текст появится в месте курсора.

**Дополнительно:**

- **Два быстрых нажатия F9** (нажать-отпустить-нажать) включают непрерывный режим — программа пишет всё подряд, пока снова не нажмёшь F9.
- Твой буфер обмена не портится — программа аккуратно сохраняет и возвращает то, что было в нём до вставки.

## Если что-то пошло не так

### В трее написано «CPU mode (no GPU)»

Программа не увидела видеокарту NVIDIA и переключилась на процессор. Это не ошибка — просто медленнее.

- Если карта NVIDIA есть — проверь Шаги 2–3 (драйвер не установлен или устарел).
- Если карты нет — так и должно быть, всё работает на процессоре.

### Текст не появляется / в логе «Audio is SILENT»

Программа записывает с неправильного микрофона.

- Проверь, что микрофон подключён и включён: **Параметры → Система → Звук → Ввод**, выбери нужный микрофон и убедись, что громкость не на нуле.
- Проверь доступ к микрофону: **Параметры → Конфиденциальность → Микрофон** → разреши доступ.

### Windows или антивирус блокирует файл

Смотри Шаг 5 — запускай через «Подробнее → Выполнить в любом случае» и добавь файл в исключения антивируса.

### Где логи (если нужно показать кому-то ошибку)

Программа пишет журнал в файл `%TEMP%\voicebutton.log`. Вставь этот путь в проводник, чтобы открыть файл.

## Для продвинутых: запуск из исходников

Если хочешь запустить из исходного кода (а не готовый EXE), понадобится чуть больше:

1. Установи Python 3.12.
2. Установи драйвер NVIDIA (Шаг 2 выше) **плюс** библиотеки CUDA 12 и cuDNN 9 — для работы GPU из исходников. Официальная инструкция: [faster-whisper → GPU](https://github.com/SYSTRAN/faster-whisper#gpu).

```bash
git clone https://github.com/NIKITANDRRR/voicebuttonwindows.git
cd voicebuttonwindows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python voicebutton.py
```

Запускать тоже нужно от имени администратора.
