# VoiceButton — пошаговая настройка компьютера

> Инструкция для тех, кто ставит программу с нуля: как проверить видеокарту, установить драйвер NVIDIA, выбрать нужную версию и запустить диктовку. Выполняйте шаги по порядку.
>
> English version: [SETUP_GUIDE_EN.md](SETUP_GUIDE_EN.md)

---

## Что делает программа

VoiceButton печатает то, что вы говорите. Зажмите F9, скажите фразу, отпустите F9 — текст появится там, где стоит курсор: в Telegram, Word, браузере, письме.

Если в компьютере есть видеокарта NVIDIA, распознавание идёт быстро. Без NVIDIA программа тоже работает, но медленнее.

---

## Что понадобится

| Что | Зачем |
|---|---|
| Windows 10 или 11 | система, на которой работает программа |
| Видеокарта NVIDIA | ускоряет распознавание речи |
| Драйвер NVIDIA | без него программа не увидит видеокарту |
| Микрофон | сюда вы говорите |

Полный «CUDA Toolkit» (набор инструментов для разработчиков на несколько гигабайт) устанавливать не нужно. Для готовой программы достаточно обычного драйвера NVIDIA — в разговорах его часто называют «CUDA-драйвером».

---

## Шаг 1. Проверьте, есть ли видеокарта NVIDIA

1. Нажмите **Win + X** (или правой кнопкой по кнопке «Пуск»).
2. Откройте **«Диспетчер устройств»**.
3. Раскройте пункт **«Видеоадаптеры»**.
4. Дальше два варианта:
   - В списке есть **«NVIDIA GeForce …»** — карта на месте, переходите к шагу 2.
   - Только **«Intel …»** или **«AMD …»** — карты NVIDIA нет. Программа будет работать на процессоре; переходите сразу к шагу 4.

---

## Шаг 2. Установите драйвер NVIDIA

Драйвер — программа, благодаря которой Windows умеет работать с видеокартой. Ставится один раз.

### Способ А — через приложение NVIDIA (автоматически)

1. Скачайте NVIDIA App или GeForce Experience с сайта `https://www.nvidia.com/`.
2. Установите и откройте его.
3. Вкладка **«Драйверы»** → **«Проверить наличие обновлений»** → **«Установить»**.
4. После установки перезагрузите компьютер.

### Способ Б — вручную с сайта NVIDIA

1. Откройте страницу поиска драйверов: `https://www.nvidia.com/download/index.aspx`.
2. Выберите серию и модель карты (например, GeForce RTX 3060), систему (Windows 10/11, 64-bit) и язык.
3. Нажмите **«Поиск»**, скачайте предложенный файл и запустите его.
4. Перезагрузите компьютер.

---

## Шаг 3. Проверьте драйвер

1. Нажмите **Win + R**, введите `cmd`, нажмите Enter.
2. В чёрном окне наберите `nvidia-smi` и нажмите Enter.
3. Видите таблицу с названием карты и версией драйвера — всё установлено.
4. Появилось `nvidia-smi не является внутренней или внешней командой` — драйвер не встал, вернитесь к шагу 2.

---

## Шаг 4. Скачайте программу и выберите версию

На странице [Releases](https://github.com/NIKITANDRRR/voicebuttonwindows/releases) лежат два готовых файла. Выбор зависит от объёма видеопамяти (VRAM):

| Файл | Нужно видеопамяти | Типичные карты |
|---|---|---|
| `voicebutton-medium.exe` | от 6 ГБ | RTX 2060, 3060, 4060 |
| `voicebutton-large.exe` | от 10 ГБ | RTX 3080, 4070, 4080 |

Как узнать объём видеопамяти:

1. **Ctrl + Shift + Esc** — откроется Диспетчер задач.
2. Вкладка **«Производительность»** → слева **«Графический процессор» (GPU)**.
3. Строка **«Выделенная память ГП»** — это и есть видеопамять.

Если сомневаетесь, берите `voicebutton-medium.exe`: он подходит большинству современных карт, а точность распознавания русского и английского у него уже высокая.

---

## Шаг 5. Запустите программу

> ⚠️ Программа должна быть запущена от имени администратора — иначе она не сможет отслеживать клавишу F9 и работать не будет.

1. Найдите скачанный `.exe`-файл.
2. Правой кнопкой → **«Запуск от имени администратора»**.
3. Если Windows SmartScreen спросит, запускать ли файл: **«Подробнее»** → **«Выполнить в любом случае»**. Это стандартное предупреждение для программ не из магазина.
4. Если файл заблокирует антивирус — разрешите его. Исходный код программы открыт и лежит в этом репозитории.

Чтобы не выбирать «от имени администратора» каждый раз: правой кнопкой по файлу → **«Свойства»** → вкладка **«Совместимость»** → включите **«Запускать эту программу от имени администратора»** → **ОК**.

---

## Шаг 6. Первый запуск

При первом запуске программа скачает модель распознавания речи: примерно **1,5 ГБ** для medium и **3 ГБ** для large. Это происходит один раз; дальше модель хранится локально в `C:\Users\<имя>\.cache\huggingface\hub\`.

Пока идёт загрузка, показывается окно «Downloading Whisper … model» — дождитесь окончания. После загрузки в трее (возле часов) появится значок микрофона: зелёный — готов к работе, красный — идёт запись.

Программа не открывает окно, она работает в трее. Выход — правый клик по значку микрофона → **Exit**.

---

## Шаг 7. Проверьте, что всё работает

1. Откройте любой редактор (Блокнот, Word) или чат.
2. Поставьте курсор туда, куда нужен текст.
3. Зажмите **F9** и говорите.
4. Отпустите **F9** — через секунду текст появится в месте курсора.

Ещё два момента:

- Два быстрых нажатия F9 включают непрерывную запись — программа пишет, пока вы снова не нажмёте F9.
- Буфер обмена не страдает: программа сохраняет его содержимое перед вставкой и возвращает обратно.

## Если что-то не работает

### В трее «CPU mode (no GPU)»

Программа не нашла видеокарту NVIDIA и работает на процессоре. Это не ошибка, просто медленнее. Если карта всё-таки есть, проверьте шаги 2–3: скорее всего, драйвер не установлен или устарел.

### Текст не появляется, в логе «Audio is SILENT»

Запись идёт с не того микрофона. Проверьте, что микрофон подключён и выбран: **«Параметры → Система → Звук → Ввод»**. И что доступ к микрофону разрешён: **«Параметры → Конфиденциальность → Микрофон»**.

### Windows или антивирус блокирует файл

См. шаг 5.

### Где логи

Лог программы лежит в `%TEMP%\voicebutton.log` — вставьте этот путь в проводник, чтобы открыть файл.

## Запуск из исходников

Понадобится Python 3.12, драйвер NVIDIA и библиотеки CUDA 12 + cuDNN 9 (для работы на GPU). Как их устанавливать — в инструкции [faster-whisper, раздел GPU](https://github.com/SYSTRAN/faster-whisper#gpu).

```bash
git clone https://github.com/NIKITANDRRR/voicebuttonwindows.git
cd voicebuttonwindows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python voicebutton.py
```

Запускать тоже от имени администратора.
